# XiangQi

912 宇宙超级无敌霸龙 Java A 课程实践项目。

一个使用 Maven 和 JavaFX 构建的 Java 21 桌面应用。

Maven~JFX结构搭建由 AI 生成。

## 环境要求

- JDK 21 或更高版本
- 无需单独安装 Maven，项目已包含 Maven Wrapper

## 运行

```shell
./mvnw javafx:run
```

## 构建

```shell
./mvnw clean package
```

## 项目结构

```text
src/main/java/org/universe912/demo/          Java 源代码
src/main/resources/org/universe912/demo/     FXML 与 CSS 资源
src/main/java/module-info.java      JavaFX 模块配置
```
